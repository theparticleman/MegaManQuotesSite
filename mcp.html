Mega Man Quotes

The Mega Man Quotes MCP (Model Context Protocol) server lets AI assistants like Claude access quotes directly. The server is available via HTTP POST at https://api.megamanquotes.com/mcp.

Tools

Tools can be invoked by an AI assistant to retrieve quotes.

get_random_quote

Get a randomly selected quote from the collection. Takes no parameters.

get_quote_by_id

Get a specific quote by its unique identifier.

Parameters

{
    'id': 'The unique identifier of the quote'
}

search_quotes

Search for quotes by author, source, or text content.

Parameters

{
    'query': 'The search term to find in quotes'
}

Resources

Resources can be read directly by an AI assistant using their URI.

quotes://random

A random quote from the collection. Returns a different quote each time it is read.

quotes://quote/{id}

A specific quote identified by its unique ID.

Response format

All tools and resources return quote data as plain text in the following format:

"Quote text here"
— Author Name, Source
(ID: 1234, Permalink: https://megamanquotes.com/?id=1234)
